How to draw your own kasuri

Kasuri (絣) is Japanese ikat: the pattern is bound off and dyed into the threads before anything is woven, so it only appears as the cloth comes off the loom.

The two boxes above are pictures of the cloth, one per thread system. Characters: # indigo (dyed), . undyed, + accent. Anything else is read as #, blank lines are ignored, and short lines are padded.

  • Warp box — every column is one warp thread. Reading down a column gives the dye sequence tied onto that thread before it is dressed on the loom.
  • Weft box — every row is one weft pick. Reading across gives that pick's dye sequence.
  • Both pictures tile across the cloth and may be different sizes — a one-line warp box is a plain set of stripes.

The cloth is a plain weave, so at each crossing either the warp or the weft floats on top, in a checkerboard. A crossing reads solid only where warp and weft carry the same colour — true tate-yoko-gasuri, double ikat. Where only one of the two is dyed you get the half-tone speckle that gives kasuri its feathered edge. Try dyeing a shape in the warp box only.

The Drift sliders slide a layer along its own threads, one pattern tile per cycle: 0 is still, negative runs the other way. Drifting one layer pulls the design out of register — the thing a kasuri weaver spends the whole cloth fighting.

To keep a design: press Preset code, then paste the printed entry into the PRESETS object near the top of the script in page3/index.html. Give it a unique key and label; the menu is built from that object, so it shows up on the next reload.
